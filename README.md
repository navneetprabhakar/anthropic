# Anthropic Chat Service

> A Spring Boot REST service that talks to Anthropic's Claude models through Spring AI.

A small, focused Spring Boot application that exposes a REST endpoint for generating chat responses from Anthropic's Claude API. It uses the Spring AI `ChatClient` abstraction to send a user message (with a configured system prompt) to Claude and return the model's reply along with the time taken to produce it.

## Features

- REST endpoint for sending a prompt to Claude and receiving a generated response
- Configured system prompt applied to every request
- Per-request timing (the response includes how long the call took, in milliseconds)
- Built on the Spring AI Anthropic starter, so the model, temperature, and base URL are externally configurable
- Request/response logging via SLF4J

## Tech Stack

- **Java 21**
- **Spring Boot 4.1.0-M1**
- **Spring AI 2.0.0-M2** (`spring-ai-starter-model-anthropic`)
- **Spring Web** (REST)
- **Lombok**
- **Maven** (with the Maven Wrapper)

## Getting Started

### Prerequisites

- JDK 21
- An Anthropic API key

### Build

```bash
./mvnw clean install
```

### Run

```bash
export ANTHROPIC_API_KEY=your-anthropic-api-key
./mvnw spring-boot:run
```

The application starts on the default port `8080`.

## Configuration

Configuration lives in `src/main/resources/application.yaml`. The API key is read from an environment variable; no secrets are committed to the repository.

| Key | Description |
| --- | --- |
| `ANTHROPIC_API_KEY` (env) | Your Anthropic API key, referenced as `spring.ai.anthropic.api-key` |
| `spring.ai.anthropic.base-url` | Anthropic API base URL (`https://api.anthropic.com`) |
| `spring.ai.anthropic.chat.options.model` | Claude model id (`claude-sonnet-4-5`) |
| `spring.ai.anthropic.chat.options.temperature` | Sampling temperature (`0.8`) |

## API

### `POST /v1/chat/stateless`

Sends a single message to Claude and returns the generated response.

**Request body** (plain text):

```bash
curl --location 'http://localhost:8080/v1/chat/stateless' \
  --header 'Content-Type: text/plain' \
  --data 'Tell me something about Spring AI.'
```

**Response** (JSON):

```json
{
  "response": "…model-generated reply…",
  "timeTaken": 1234
}
```

| Field | Type | Description |
| --- | --- | --- |
| `response` | string | The text generated by Claude |
| `timeTaken` | long | Time taken to produce the response, in milliseconds |
